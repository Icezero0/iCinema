## 实测结果（以本节为准）

第三阶段补充：已使用实际实现的请求客户端、解析器和导入任务在隔离临时数据库验证完整入库。首次导入1部作品、11个播放项，第二次同源作品为“无变化”，没有重复创建；详见 [第三阶段实测记录](../reports/cms-stage-03-live-check.json)。本次不再以分片是否播放作为导入验收条件。

**按用户确认的接入标准，金鹰已通过可用性验证：能够取得作品、剧集和 M3U8 地址，可继续自动导入开发。** 单条线路是否即时可播放不作为接入或导入的前置条件；失效线路由多线路选择应对，不保证每条线路始终可用。本次请求不携带登录 Cookie 或验证码，使用项目现有 venv 的 urllib；顺序请求，采集翻页及媒体跟进请求间隔至少 1.3 秒，响应读取有大小和超时限制。

### 对开发的实际影响

- 可以继续实现自动导入：作品 ID、名称、分类、年份、地区、播放组和各集地址已取得；不用网页搜索，因此此次网页验证码没有阻断采集。
- `ac=list` 的播放地址为空，必须请求 `ac=detail&ids=…`。详情的 `vod_play_from` 为线路组标识，`vod_play_url` 以 `$$$` 分组、`#` 分集、`$` 分隔集名与地址；本次选用的专用接口返回一个播放组。
- 响应 `Content-Type` 是 `text/html;charset=utf-8`，正文实际为 JSON；适配时应限量读取后验证 JSON 和必要字段，不能只按 MIME 拒绝，也不能把验证码 HTML 当作成功响应。分页数字部分为字符串，需要规范化。
- 分片超时保留为观测记录，不阻塞金鹰接入、自动导入或后续阶段，也不据此丢弃已取得的播放项。线路可用性与导入成功分开处理；不将本次结果表述为完整播放通过。多来源及房间切线按既定阶段实现，不把一次失败自动升级为整个作品禁用。
- 2026-09-18 已补充验证批量详情 ID、分类与相对小时增量参数、分页详情及页大小，详见[增量参数评估](../reports/jinying-incremental-assessment.md)。云播接口、XML 备选、全站稳定性和长期限流策略仍未验证；增量调度尚未实现。

## 结论与接入选择

符合当前采集适配方向。帮助页列出苹果 CMS 兼容接口，并区分 M3U8 与云播；同一来源可以包含多种线路，适合“作品 → 剧集 → 线路播放项”的模型。

| 用途 | 帮助页列出的地址 |
| --- | --- |
| 通用采集 | `https://jyzyapi.com/provide/vod` |
| M3U8 JSON，第三阶段优先选择 | `https://jyzyapi.com/provide/vod/from/jinyingm3u8/at/json` |
| 云播 JSON | `https://jyzyapi.com/provide/vod/from/jinyingyun/at/json` |
| XML 备选 | `https://jyzyapi.com/provide/vod/at/xml/` |

帮助页还列有解析播放器入口。iCinema 优先使用自身已有 HLS 引擎，不需要安装站方提供的 CMS 播放器文件。云播页面不能直接作为 HLS 地址加载，第二阶段允许记录为“外部播放器页面”，不嵌入执行该页面，也不计入可直接预览的线路数。

## 第三阶段实施依据

- 帮助页说明搜索接口关闭：导入采用分类、分页、详情，不依赖关键词搜索接口。具体参数及支持程度须实测。
- 帮助页建议请求间隔超过 1 秒：初始串行请求，间隔至少 1.2 秒，增加超时、有限重试、页数和条数上限。
- 帮助页站点导航存在“日本动漫”；通过实际分类接口确认其 ID 后映射至站内 `japanese_animation`，不推测分类 ID，也不直接假定所有“动画片”都属于日本动画。
- 验证列表与详情字段、上游 ID、播放组标识、集名和地址拆分方式，保留原始集名，无法可靠识别的集数交由管理员处理。
- 少量读取确认 JSON 内容和分类，再验证一项资源的播放地址、HTTPS、CORS 和格式；站点可访问不代表浏览器可播放。测试阶段不批量拉取全站。
- 帮助页建议在失败时改用 HTTP；实现不会自动降级，先显示连接失败并排查。

当前无需用户补充账号或密钥。若实际接口要求认证、限制访问或分类无法确定，再依据实际返回确认。

## 作品分季方式补充核对

同日尝试站内搜索“夏目友人帐”，站点返回安全验证码页面，未获取站内搜索结果。通过公开索引查到并读取[《转生为第七王子，随心所欲的魔法学习之路 第二季》详情](https://jinyingzy.net/index.php/vod/detail/id/82639.html?ac=detail)：该季作为独立作品展示，标题包含“第二季”，元信息列出别名、类型、地区、语言、年份，下方按金鹰云/M3U8 分组列出剧集。此例支持按完整标题分别建档；不据此断言所有接口都没有季号字段。

按用户反馈，iCinema 移除独立季号字段。导入保留完整标题和上游作品 ID，作品内按集号及篇目类型关联播放项；后续名称规范化也不得抹掉“第二季/第2期”等区分信息。本次只读取详情文字，未请求媒体文件。
